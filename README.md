# voidx


Суть мессенджера в чем? В условиях нестабильности, то есть отсутствия постоянного стабильного доступа в сети стоит придумать какое-то средство связи, которое не будет подвержено какому-либо воздействию. И поэтому нужна децентрализованность. И поэтому есть VoidX

Принцип заложен в том, что у VoidX нету серверов (пока что). Мессенджер передает данные по другим каналам связи. Самый очевидный пример - блютуз

Но ведь блютуз недальнобойний. В чем тогда смысл? Тут и приходит еще больше смысла. Каждый пользователь является узлом в сети всего мессенджера. суть в том, что если писатель не достает сам до получателя сообщения, то он передает сообщение другим людям, которое потолм доходит до читателя. При чем прочитать сообщение может только читатель.
